## 2026-06-29 Source Badge Icon Dependency

- Status: Accepted
- Topics: shared-web, badges, icons
- Refs: runtime/web/src/SourceBadge.tsx, runtime/web/src/LinkBadgeBase.tsx
- Decision: Add `SourceBadge` as a sibling wrapper to `BrandBadge` over an internal `LinkBadgeBase`, use `react-icons` for source-code icon presets, and auto-select the GitHub icon for `github.com` hrefs unless `iconName` is explicitly set.
- Rationale: `BrandBadge` and `SourceBadge` share rendering, sizing, styling, and unstyled behavior, but neither is conceptually the parent of the other. Existing consumer apps already use `react-icons`, and it provides both generic source-code icons and a GitHub icon without adding a second icon standard. GitHub is the expected source host for these portfolio apps, so detecting it in the default path keeps consumer markup cleaner while preserving explicit overrides.
- Alternatives: Make `SourceBadge` wrap `BrandBadge`; add `lucide-react`; paste inline SVG paths; require every consumer to pass its own icon; require `iconName="github"` on every GitHub source link.
